# PhoneShop-Online
Hệ thống quản lý cửa hàng bán điện thoại online.

Mô tả:
Thiết kế hệ thống với UML (Use Case Diagram, Class
Diagram, Sequence Diagram). Tạo giao diện người dùng trên
FIGMA với trải nghiệm đơn giản và trực quan.

Công cụ: UML, FIGMA, Lucidchart.

Kết quả: Hệ thống mẫu sẵn sàng triển khai, giúp quản lý hiệu
quả các quy trình bán hàng trực tuyến.
